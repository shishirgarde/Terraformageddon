Mission Briefing · Level 2

Situation
The Uptimely app service is stuck on boot. It's looking for config/app.conf — a config file that should sit inside a config/ directory next to the binary. Neither exists. The previous engineer deleted them by hand and didn't update Terraform. Now nothing knows where the truth lives.
Your Mission
Write the Terraform from scratch. Only the provider block is pre-filled — the rest is up to you. Then run the real terraform commands yourself in the terminal at the bottom of the screen.
How to fix it
1
Write a local_file resource that creates config/app.conf with content mode=production
2
Type terraform init in the terminal to download the provider
3
Type terraform plan to simulate. Then terraform apply to execute. Never skip the plan.
4
When the service is back up, terraform destroy for a clean teardown
